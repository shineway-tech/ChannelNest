# 图片生成按钮任务状态设计

## 目标

图片任务提交后，在服务端排队和生成期间持续显示明确的进行中状态，防止用户误以为点击无效或重复创建任务。

## 状态规则

- 尚未提交任务：按钮可用，显示“生成图片”。
- 正在提交请求：按钮禁用，显示旋转图标和“生成中”。
- 任务状态为 `pending` 或 `processing`：按钮继续禁用并显示“生成中”。
- 任务状态为 `succeeded`、`partial` 或 `failed`：按钮恢复可用并显示“生成图片”。
- 提交请求失败：按钮恢复可用，现有结果区继续显示具体错误。

## 实现范围

- 在页面渲染层根据 `busy` 与图片任务状态计算是否正在生成。
- 复用现有旋转图标样式和中英文“生成中”文案，不引入新的全局状态。
- 在控制器入口增加同样的任务状态保护，避免仅依赖按钮禁用。

## 验证

- 前端 TypeScript 构建通过。
- 静态检查确认进行中状态会禁用按钮并切换文案。
- 客户端热更新后，任务开始到结束期间按钮状态保持稳定。
